1. Фундамент: Терминал, сейф .env и git worktree

  • CLI / Shell (Терминал): Прямой текстовый пульт управления компьютером и сервером без графических оболочек.
  • .env (Environment Variables): Изолированный файл для API-ключей и паролей (OPENAI_API_KEY, TELEGRAM_BOT_TOKEN). Всегда добавлен в .gitignore, чтобы секреты не утекли в Git.
  • git worktree: Позволяет открыть 2–3 ветки кода одновременно в разных папках (на одном общем .git-хранилище), чтобы параллельные ИИ-агенты не перезаписывали файлы друг друга.

4. Webhooks vs Polling и Симулятор реальных сбоев

  • Polling (Опрос): Бот каждые 2 секунды сам спрашивает сервер Telegram: «Есть новые сообщения?». Тратит ресурсы впустую и даёт задержку.
  • Webhook (Обратный вызов): Звонок в домофон. Telegram или платёжная система сама делает мгновенный POST-запрос на ваш https:// адрес за Nginx — но только при наличии валидного SSL-сертификата.

5. Проверка понимания (Quick Checks)

1. Вы запускаете двух ИИ-агентов в репозитории одновременно: один чинит бота, второй пишет интеграцию оплаты. Какой инструмент защитит файлы от взаимной перезаписи?
2. Зачем в docker-compose.yml для n8n указывают строку ports: ["127.0.0.1:5678:5678"] и раздел volumes?
3. Почему для веб-интерфейса n8n за Nginx Reverse Proxy обязательно прописывают заголовки Upgrade и Connection, а на самом сервере поднимают Certbot?
4. Что вернёт Nginx клиенту, если ваш внутренний FastAPI-бэкенд за ним временно упал?

Боевой чек-лист перехода от Скрипта к Системе

1) Проверьте .gitignore — файл .env никогда не коммитится. 2) Опишите сервис в docker-compose.yml с volumes и restart: always. 3) На VPS закройте порты через UFW (только 22, 80, 443) и отключите пароли SSH. 4) Поставьте Nginx Reverse Proxy с Certbot и переключите ботов на Webhooks.
