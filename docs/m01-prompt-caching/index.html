1. Анатомия контекста и когнитивная стена

Современные модели поддерживают контекст вплоть до 2 000 000 токенов (Google Gemini 1.5 Pro). Однако в реальных автономных агентах или длинных диалогах линейное увеличение контекста на каждом шаге приводит к двум фундаментальным проблемам:

1.1. Экспоненциальный рост расходов (Token Economics)

Если спецификация MCP-инструментов и системная роль занимают 15 000 токенов, а агент делает 20 шагов в цикле ReAct, суммарно инференс обрабатывает свыше 300 000 входных токенов, повторно пересчитывая одно и то же!

1.2. Эффект «Lost in the Middle» (Context Decay)

Внимание модели распределяется неравномерно. Информация, расположенная в середине сверхдлинного контекста, извлекается с меньшей точностью, чем факты в начале (*Primacy*) или конце (*Recency*).

2. Как устроен Prompt Caching под капотом

При стандартном запросе графический процессор (GPU) производит умножение матриц для вычисления промежуточных векторов ключей и значений внимания — KV-Cache (Key-Value Cache). Технология Prompt Caching сохраняет вычисленный KV-кэш в оперативной памяти инференс-кластера.

Визуализация: Принцип префиксного совпадения (Prefix Match)

Кэш попадает в цель (Cache Hit) только если последовательность токенов от начала промпта идентична до последнего символа.

✓ ПРАВИЛЬНО: Статический блок в начале (Cache Hit 90% скидка):

System Prompt (10k) MCP Tools (5k) Knowledge Base (5k) User: "Привет" (50)

✗ ОШИБКА: Динамический таймстемп в первой строке (Cache Miss! 0% скидки):

Time: 15:32:01 (4) System Prompt (10k) MCP Tools (5k) User: "Привет" (50)

3. Сравнение провайдеров в 2026 году

Провайдер Управление Минимальный порог Скидка на чтение TTL (Время жизни)
Anthropic Claude (3.5 Sonnet / Haiku) Явные брейкпоинты (до 4 точек) 1 024 токена (Sonnet) / 2 048 (Haiku) 90% скидка 5 мин (rolling)
OpenAI (GPT-4o, o3-mini) Автоматическое (блоки по 128 токенов) 1 024 токена 50% скидка Динамический (5–10 мин)
Google Gemini (1.5 Pro / Flash) Явный объект CachedContent 32 768 токенов 75% скидка Фиксированный (от 1 часа)

Синтаксис Anthropic с Breakpoint:

import anthropic

client = anthropic.Anthropic()
response = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=1024,
    system=[{
        "type": "text",
        "text": "Статическое ТЗ и спецификация инструментов...",
        "cache_control": {"type": "ephemeral"}  # Контрольная точка кэша
    }],
    messages=[{"role": "user", "content": "Выполни анализ..."}]
)
# response.usage.cache_read_input_tokens -> количество токенов со скидкой 90%!
