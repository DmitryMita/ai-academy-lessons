1. Архитектура устойчивости: Ловушка веб-чата vs Суверенный стек

  • Single Point of Failure (SPOF): Когда инструкции (Projects), память и история диалогов заперты внутри claude.ai, блокировка аккаунта мгновенно обнуляет рабочий контекст.
  • Принцип «Own Your Context»: Вся долговременная память (регламенты, схемы БД, история решений) хранится у вас в Markdown/Git (как knowledge_base/) или локальной БД.
  • Слой абстракции (API Gateway): Код ботов, парсеров и агентов обращается к моделям через единый интерфейс (OpenRouter / LiteLLM), позволяя сменить провайдера за 1 строчку в .env.

2. Подготовка к бану и перенос истории (conversations.json)

Выгрузка в Claude: Settings → Privacy → Export data. Внутри архива лежит файл conversations.json (массив диалогов с полями uuid, name, created_at, chat_messages[], где sender = "human" или "assistant").

Скрипт авто-архивации conversations.json → Markdown (.md)

import json
from pathlib import Path

export_data = json.loads(Path("conversations.json").read_text(encoding="utf-8"))
out_dir = Path("archive_md")
out_dir.mkdir(exist_ok=True)

for conv in export_data:
    title = (conv.get("name") or conv["uuid"][:8]).replace("/", "-")
    lines = [f"# {title}\n", f"- Created: `{conv.get('created_at')}`\n\n---\n"]
    for msg in conv.get("chat_messages", []):
        role = "USER" if msg.get("sender") == "human" else "CLAUDE"
        lines.append(f"### {role}\n{msg.get('text', '')}\n\n")
    (out_dir / f"{conv['uuid'][:8]}_{title[:40]}.md").write_text("".join(lines), encoding="utf-8")

3. Claude через API в неподдерживаемых странах: пути и риски

Официальная политика Anthropic (Supported Regions Policy) едина для claude.ai, Claude Code и Console API: ограничения действуют по физическому местоположению, регистрации компании и контролю ≥50% из неподдерживаемых юрисдикций.

Маршрут доступа Как работает аутентификация Плюсы Риски и ограничения
1. Прямой Anthropic Console
api.anthropic.com/v1/messages		 Заголовки x-api-key + anthropic-version Все новые фичи в день релиза: Prompt Caching, Message Batches (-50%), Files API Нарушение ToS из неподдерживаемой страны; риск блокировки Console и заморозки предоплаченного баланса
2. Единый шлюз (OpenRouter)
openrouter.ai/api/v1		 Ключ Bearer (OpenAI SDK формат) Оплата единым балансом, доступ к Claude + GPT + Gemini, авто-Fallback и проброс cache_control Небольшая наценка/комиссия шлюза; завязка на стабильность посредника (решается через LiteLLM)
3. Облака (AWS Bedrock / GCP Vertex AI) AWS IAM (SigV4) или GCP ADC Корпоративный SLA, изоляция данных (Data Residency) в регионе EU/US Сложный онбординг юрлица; часть фич (Files API, Batches) приходит позже или отсутствует 

  


  
  

    
4. Ограничения API vs подписка Claude.ai Pro ($20/мес)

    

      

        
          

            Критерий
            Claude.ai Pro ($20/мес)
            Claude API (Direct / OpenRouter)
          

        
        
          

            Состояние (State)
            Авто-история + кросс-чат Memory
            Stateless: сервер ничего не помнит — передаёте весь массив messages каждый раз
          

          

            Projects & Artifacts
            Встроены в интерфейс (папки, превью React/SVG)
            Отсутствуют: заменяются System Prompt + Prompt Caching / RAG и своим UI (или Open WebUI)
          

          

            Лимиты нагрузки
            Жёсткие 5-часовые окна и недельные капы
            Тройной лимит по Tier (Start / Build / Scale): RPM, ITPM, OTPM + Token Bucket (burst вызовет 429)
          

          

            Защита бюджета
            Потолок цены — $20/мес
            Без Spend Limit баг в цикле агента сожжёт весь баланс за минуты
