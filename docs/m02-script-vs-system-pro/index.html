1. Гигиена разработки: .env Fail-Fast и git worktree

  • .env + pydantic-settings: Секреты (TELEGRAM_BOT_TOKEN, N8N_ENCRYPTION_KEY) лежат отдельно от Git с правами chmod 600 .env. Валидация через BaseSettings даёт Fail-Fast при старте контейнера, а не падение на живом клиенте.
  • git worktree add <path> -b <branch>: Создаёт физически отдельную папку под ветку при общей базе .git (экономит гигабайты и изолирует агентов в Antigravity / Claude Code).
  • Граничные правила Git: Одну ветку нельзя открыть в двух worktree сразу. После ручного удаления папки обязательно запускайте git worktree prune, чтобы очистить осиротевшие блокировки в .git/worktrees/ (иначе — git worktree remove).

4. Отладка в терминале и Симулятор инцидентов (502 / 504 / Webhooks)

  • 502 Bad Gateway vs 504 Gateway Timeout: 502 означает, что внутренний бэкенд (127.0.0.1:8000) мёртв или слушает другой порт; 504 — бэкенд жив, но не успел ответить за proxy_read_timeout (пора выносить LLM-вызов в очередь Redis).
  • Telegram Webhook vs Polling: Telegram Bot API шлёт POST строго на валидный HTTPS:443 (доверенный SSL от Let's Encrypt). Диагностика: метод getWebhookInfo показывает last_error_message и pending_update_count.
